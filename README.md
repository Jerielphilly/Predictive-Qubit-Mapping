Steps to run:
1. Activate the Environment
For Windows:
quantum_env\\Scripts\\activate

2. Install Dependencies
With the environment activated (you should see (quantum_env) in your terminal prompt), install the required packages:
pip install -r requirements.txt

3.How to Run Phase 1
python demo.py

note: pip freeze > requirements.txt in their terminal, and it will automatically update requirements.txt file with all the new dependencies
